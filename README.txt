■ 機能
全630問、8枚でのテーマ重複防止、4人のキャラクター、
BGM、効果音、話す人の選択、トークタイマーを維持しました。

■ このZIPのオフライン使用
HTTPSサイト（GitHub Pages等）にZIP内のファイルをすべて配置し、
初回オンラインアクセスでService Workerに読み込ませてから
ホーム画面に追加してください。
前のバージョンが表示される場合はオンラインで再読込してください。

■ タブレットにZIPが保存できない場合
別途提供の「MTQ_v34_TABLET_SINGLE.html」は画像と音声を
1ファイルに内蔵しています。HTML版をダウンロードしてください。
アプリによっては端末のファイルビューアでJavaScriptが制限される場合があります。
その場合はSafariやChromeでHTTPS版を開いてください。
